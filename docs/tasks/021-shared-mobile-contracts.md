# 021 — Спільні TypeScript-модулі та платформні адаптери

Статус: Спільне ядро й контракти реалізовано; перенесення бізнес-UI/підключення транспортів триває в залежних задачах. Пріоритет: P0. Залежності: [020](020-mobile-feasibility.md).
Батьківський план: [Android plan](../MOBILE_ANDROID_PLAN.md).

[Реалізація, матриця компонентів і перевірки](../testing/021-shared-mobile-contracts/README.md).
Android-приймання 020 ще відкрите; кодову частину продовжено за прямою вказівкою користувача.

## Мета

Повторно використати модель та UI Shopik без імпорту Next.js server runtime у мобільну збірку.

## Роботи

- Виділити незалежні моделі/валідацію з `products`, `money`, `tags`, `categories`, `expenses`, `identity`, `shopping`, `theme`, `list-model`, `workspace-name` і актуальні типи БД. Зберегти OR, quantity, plan/actual і серверні SHA256 ID.
- Ввести вузькі TypeScript-інтерфейси auth, читання/запису, navigation, local storage, lifecycle, theme та invitation links. У спільній моделі не залишати `HTMLElement`, Next cookies або server-only imports.
- Відокремити від компонентів імпорти `app/**/actions`, `next/navigation`, `next/image`, `next/link` і `next/font`. Вебадаптери зберігають SSR/cookie; мобільні адаптери надаються окремо.
- Визначити мінімальні пакети `packages/` і npm workspaces лише за потреби. Не переносити все механічно та не додавати монорепо-фреймворк.
- Скласти матрицю компонентів: повторне використання, адаптер або платформна реалізація. Шрифти й бренд-ресурси мають бути локальними.

## Критерії готовності

- Спільна модель компілюється без Next.js, DOM-залежні деталі UI винесені на відповідний рівень.
- Вебверсія зберігає поведінку та результати наявних тестів; модель не копіюється у два незалежні набори.
- Мобільний граф імпортів не містить Node crypto/server-only/Server Actions. Постійні ID продуктів не замінені UUID.
- Немає непотрібних бібліотек. Нові функції, компоненти й значущі HTML-секції мають коментарі за AGENTS.md.

## Перевірки

На вебі: lint, typecheck, unit, production build; для торкнутих auth/workspace/shopping-сценаріїв — відповідні наявні регресії. Перевірити збіркою межу імпортів спільного пакета. Результат і матрицю зберегти в `docs/testing/021-shared-mobile-contracts/`.
