## Що змінилось

- Єдина allowlist, назви й тип Theme покривають light, dark, pink, light-blue, light-green, light-pink. Pink має рожеві фон, поверхні й поля; light-* — нейтральну основу й кольорові кнопки. CSS color-scheme — лише light/dark.
- ThemeProvider у layout узгоджує налаштування й компактний native select хедера, pending і точний rollback. Новий профіль оновлює вибір без перемонтування оболонки; зміна акаунта скидає стан. Збережено серверну дію, пріоритет профілю, світлий fallback та HttpOnly cookie.
- Нова міграція 009 розширює лише CHECK profiles.theme, не змінюючи даних, default, grants і RLS. Міграція 007 не переписана. Інструкції оновлені в DATABASE/SUPABASE.
- Налаштування: дві рівні колонки від 768 px, теги/категорії на всю ширину; нижче — одна колонка. DOM-порядок і якорі збережені.
- Поля мають один outline з offset 0 без додаткової тіні; aria-invalid зберігає червоний фокус. Інші елементи зберігають видимий клавіатурний фокус.
- `.product-cards` відокремлює кожний активний продукт поверхнею, рамкою й проміжком 16 px. Сьогоднішні картки мають тематичне виділення без негативних відступів. Історія витрат лишається в `.product-rows`.
- Місячна сума, зрозумілий період і UAH розміщені над кільцем. Великі суми не перекривають графік; довгі категорії переносяться. При багатьох категоріях обидві колонки вирівняні угорі. Нульові категорії лишаються доступними текстом, кільце має нейтральний fallback без ділення на нуль. Збережені існуючі loading/error стани ExpenseList.
- Hover більше не підміняє тематичні та небезпечні кнопки нейтральним кольором. Червоні дії, власні кольори тегів і стабільні кольори категорій збережені. Прибране затемнення тексту історії витрат для читабельності.

## Неперевірені сценарії

Немає підтвердженої авторизованої Google-сесії й SQL-доступу. Міграція 009 на hosted Supabase не застосована; SQL/RLS тест `supabase/tests/color_themes.sql` підготовлений, але не виконаний. Не підтверджені реальне збереження profile/HttpOnly cookie, reload/logout/login із двома акаунтами, пріоритет профілю й відсутність спалаху на повних авторизованих `/`, `/settings`, `/expenses`. Ізольовані fixture цього не замінюють. Повні CRUD, завершення, URL back/forward з AND-тегами та інші незавершені перевірки 013 не оголошуються пройденими.

Порожній місяць без категорій, серверні loading/error, усі комбінації hover/active/disabled/error/destructive, Tab-порядок і Escape/повернення фокуса кожного діалогу потребують повного сценарію зі справжніми даними; тут перевірені нульова категорія, меню та наявні локальні контроли. Контраст кастомних тегів і кожного історичного сегмента не вимірювався повторно.
