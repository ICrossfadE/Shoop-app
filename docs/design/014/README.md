# Візуальні правки Shopik — 30.10.2026

Оновлено картки покупок, модальну форму, теги, витрати, налаштування й Google-кнопку. Сума над фільтрами використовує окремий кешований список усієї вибраної категорії без тегового фільтра; оптимістичні зміни враховуються тим самим QueryCache. Суми додаються в копійках. Наявні серверні дії, OAuth, SHA256-ідентифікатори та схему бази не змінено. Нових залежностей немає.

Montserrat із кирилицею розміщується локально через `next/font/google`; інтернет потрібен під час першої збірки. Анімації секцій, станів кнопок і чисел враховують reduced-motion. Доступне текстове значення числа одразу відповідає остаточній сумі. Вибір тегів у формі зберігає клавіатурний фокус після переміщення капсули.

## Перевірки

- `npm run lint`, `npm run typecheck`, `npm test`: успішні, 32 unit-тести.
- `npm run build -- --webpack`: успішна production-збірка з перевіркою TypeScript.
- 360, 390, 768, 1440 px у двох темах: немає горизонтального переповнення на довгих назвах/тегах і максимальній ціні; кнопки дій 44 × 44 px.
- Меню: відкриття, Escape й повернення фокусу. Графік: звичайні та нульові суми.
- Справжній OrderModal в ізольованому прикладі: початкова ціна порожня, placeholder `0`, введення десяткової коми, додавання/прибирання тегів і закриття. Число доходить до нового значення, reduced-motion вимикає CSS-анімацію.
- Production `/login`: відображення Google-кнопки без помилок JavaScript. Світлий і темний мобільні приклади, логін і форму переглянуто візуально.

Скріншоти збережені в `screenshots/`. Компонентний приклад використовує запасний системний шрифт, production-логін — Montserrat. Це не перевірка реальної Google-сесії, збереження продуктів або RLS. Для форми використовуються локальні заглушки лише в тестовому bundle; публічних demo-маршрутів і записів у базі немає. Повний сценарій авторизованих екранів потребує сесії користувача.

## Відтворення

Після production-збірки запустити `npm run start -- --port 3014` у `shopik-app`, потім із кореня:

```powershell
node docs/design/014/check-ui.cts C:/Users/Cross/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules
```

Потрібен уже встановлений Playwright із desktop runtime та headless Edge поза sandbox. Компоненти збираються наявними Webpack і TypeScript. Перед вимірюваннями тест очікує завершення анімації входу.
