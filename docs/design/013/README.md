# Інтеграція 013 — перевірки 30.10.2026

Це результати перевірки робочих компонентів, а не новий макет. `fixture.tsx` імпортує справжні OrderCard та ExpenseChart і збирається окремо встановленими Next.js/Webpack/TypeScript. Немає публічного demo-маршруту чи тестових записів у Supabase. Умовні дані використовуються виключно ізольованим браузерним тестом.

## Відтворення

Спочатку виконати `npm run build -- --webpack` і `npm run start -- --port 3013` у `shopik-app`. Потім від кореня:

```powershell
node docs/design/013/check-ui.cts C:/Users/Cross/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules
```

Перший аргумент — шлях до вже встановленого desktop runtime з Playwright; нових тестових залежностей у застосунок не додано. Потрібен headless Edge поза обмеженнями sandbox. Проміжний bundle створюється в системній тимчасовій теці.

## Результати

- Усі 8 поєднань ширин 360, 390, 768, 1440 px та обох тем без горизонтального переповнення.
- Довга назва, опис, довгі користувацькі теги й максимальна ціна переносяться; кнопки дій мають 44 × 44 px.
- Recharts рендерить кільце на клієнті; легенда містить однаково названі різні категорії зі стабільними кольорами. Нульова сума не викликає помилок і зберігає категорію в легенді.
- Меню відкривається, Escape закриває й повертає фокус на три крапки.
- Production `/login` завантажується без JavaScript pageerror.
- Збережено 8 компонентних скріншотів та `login-light.png` у `screenshots/`. Мобільні світлий і темний приклади переглянуті візуально.
- ESLint, 24 unit-тести та TypeScript у production Webpack build успішні. Turbopack build має помилку запуску дочірнього процесу PostCSS навіть поза sandbox; скрипт збірки не замінено.

Це не перевірка захищених екранів зі справжньою Google-сесією. CRUD, RLS, URL back/forward, збереження теми після reload/logout, реальна аналітика та повна доступність залишаються для приймання 013. Великі набори категорій і максимальна загальна місячна сума також потребують окремої перевірки. Задача зберігає статус «У роботі».

## Джерела та залежності

Патерн: [shadcn.io Donut with Text](https://www.shadcn.io/charts/pie-donut-text). Сторінка нині демонструє TanStack Charts із доступом до коду через вхід. Код не копіювався. Використано незалежний React-компонент на [Recharts Pie](https://recharts.github.io/en-US/api/Pie/), Recharts 3.10.1, MIT, сумісність із React 19 перевірено за package.json. Інших chart/UI бібліотек не встановлено.

`npm audit --omit=dev` повідомляє 2 high та 1 critical у наявних Next.js/sharp/source-map-js; Recharts у звіті відсутній. Framework автоматично не оновлювався в межах редизайну.
