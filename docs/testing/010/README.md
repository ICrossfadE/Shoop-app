# 010A — IndexedDB: перший етап, 31.10.2026

Додано нативне версіоноване сховище підтверджених query snapshots та чернеток продуктів. Залежностей, змін SQL/Auth і service worker немає. Права й SHA256 ID залишаються серверними.

Кеш відновлює лише точний акаунт/Workspace/фільтр перед мережевим читанням; SSR snapshot має пріоритет. Відновлена копія застаріла, мережева помилка зберігає її на екрані. Підтверджені мутації та зміни каталогу інвалідують дискові snapshots простору. Focus/online лише оновлюють дані й не видаляють дисковий fallback. Операції очищення й запису серіалізовані. Logout, зміна акаунта й виявлена відмова доступу очищають попереднього власника.

Чернетки зберігають поля, operationId і ambiguous. Після повторного відкриття відповідної форми користувач явно відновлює або відкидає дані. Перед запитом зберігається невідомий результат, щоб після reload повторювати незмінний payload з тим самим ключем. Скасування й успішна відповідь прибирають чернетку. Це ручний повтор, автоматичної черги немає. При помилці сховища доступне попередження; онлайн-робота продовжується.

Політика поточного етапу: відновлення записів не старших 7 діб, очищення прострочених під час запису. Це не гарантія фізичного видалення через 7 діб із закритим браузером. Чернетки лише продуктів; каталог залишається у поточній оболонці. Пряме відкриття/reload застосунку без мережі ще не підтримується — серверний bootstrap залишається обов'язковим.

## Перевірки

- Unit: 34/34, включно з disk fallback при відмові мережі, точним фільтром і захистом від пізнього відновлення даних попереднього акаунта.
- TypeScript і production Webpack build успішні.
- Реальний IndexedDB у headless Edge на ізольованому HTTPS origin: reload, ізоляція акаунтів, інвалідація snapshots, очищення одного акаунта зі збереженням іншого та його чернетки — PASS. Це тест сховища, не авторизований UI-сценарій.
- ESLint: без помилок; попереднє попередження AppHeader про невикористаний ThemeToggle збережено.

node scripts/check-local-store.mjs C:/Users/Cross/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules

Остання команда використовує встановлений desktop Playwright та Edge поза sandbox, без Supabase й нових пакетів.

Не перевірено: повний авторизований UI-сценарій відновлення форми, реальні logout/account switch у кількох вкладках, Safari/Firefox, симуляція quota/blocked/versionchange, довготривале очищення. Автоматичні відкладені мутації, конфлікти, час офлайн-витрати, залежності нових категорій/тегів і запуск після закриття залишаються наступними етапами задачі 010. Hosted SQL не змінювався.
